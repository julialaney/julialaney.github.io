SECURE MESSAGE

Need to store something and don’t want to bother encrypting it yourself? The secure_storage class auto-encrypts using several layers of ciphers, and randomly generated caesar keys! Then, when you need it again, decode your information using your password and the decode function.

super_secret_content = secure_storage(message = "super secret message number 2", password = "hi")
super_secret_content.print_message()
The current message is "--././.---/..-/..../ /--././.---/..-/..../ /--./..-/.--/..../..-/..-./"
To view encryption history, provide the correct password as an argument to this function.
super_secret_content.decode(password = "hi")
Your stored message is: "super super secret"

MULTI LAYER CAESAR ENCRYPTION

The last function that this package includes is the update_key function, which is important if you are doing multiple levels of caesar encoding!

# create your message
caesar_extravoganza = cipher(message = "our most secret message yet", password = "james bond")
# say you want to do mulitple layers of caesar encoding. The cipher class only stores the last used key.
# the good news is that spies can update the key manually!
caesar_extravoganza.caesar_encode(key = 10)
caesar_extravoganza.caesar_encode(key = 15)
caesar_extravoganza.caesar_encode(key = 7)
The encoded message is: "yeb wycd combod wocckqo iod"
The encoded message is: "ntq lnrs rdbqds ldrrzfd xds"
The encoded message is: "uax suyz ykixkz skyygmk ekz"
# that message is well and truly garbled! but no fear, use update_key to decode it!

# changing it to the most recently used key
caesar_extravoganza.update_key(new_key = 7, password = "james bond")
caesar_extravoganza.caesar_decode("james_bond")

# changing it to the second most recently used key
caesar_extravoganza.update_key(new_key = 15, password = "james bond")
caesar_extravoganza.caesar_decode("james_bond")

# changing it to the first key we used!
caesar_extravoganza.update_key(new_key = 10, password = "james bond")
caesar_extravoganza.caesar_decode("james_bond")

# and bam! just like that, we're back to our original message
caesar_extravoganza.print_message()
